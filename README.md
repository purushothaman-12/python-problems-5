# Python Problems Collection

This repository contains 5 LeetCode-style Python problems with clean function-based solutions and example test cases.

## Problems included

1. Two Sum
2. Valid Palindrome
3. Merge Two Sorted Lists
4. Best Time to Buy and Sell Stock
5. Longest Substring Without Repeating Characters

## How to run

Each file is a standalone Python script. Example:

```bash
python problem_1_two_sum.py
```

## Structure

- `problem_1_two_sum.py`
- `problem_2_valid_palindrome.py`
- `problem_3_merge_two_sorted_lists.py`
- `problem_4_best_time_to_buy_and_sell_stock.py`
- `problem_5_longest_substring_without_repeating_characters.py`

## Notes

The solutions are written in a typical competitive-programming / LeetCode style:
- function-based implementation
- clear problem description
- sample input/output examples
- simple CLI validation in `__main__`
